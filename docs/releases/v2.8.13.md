# v2.8.13

## Fix

### 铁律：任何动画都不得改变卡片整体高度

**现象**：极简歌词模式进/出时，整张卡片的高度会跟着动画一起变（退出时尤其明显：控件还没展开，卡片先矮一截，再慢慢长回来）。

**根因**：v2.8.11/2.8.12 让极简模式的三块（切换器 / 播放控件 / 进度条）用 `max-height → 0` 收缩，
收缩掉的占位靠 `.wrap.mini { min-height: var(--mini-h) }` 这块**地板**撑住：
- 进极简：内容变矮，但地板撑着 → 高度不变（这一侧侥幸没问题）；
- 出极简：`.mini` class 一摘，**地板同时失效**，而控件此时还处于收起状态 → 卡片先掉一截，再随 0.6s 动画长回来 —— 高度在动画期间变化。

附带两处同类的瞬时高度变化：`.wrap.mini` 还把 `padding-top` 从 14px 改成 24px（+10px 硬跳）、
`padding-left` 20px / 封面 `margin-right: 6px`（横向 6px 硬跳）。

**修复**：三块「只隐身、不收缩」，与面板态/音量态（`panelmode` / `volmode`）完全同一套规则：

| 项目 | 修前 | 修后 |
|---|---|---|
| 极简三块 | `max-height: 0` + `overflow: hidden` 收缩 | `opacity: 0` + `translateY(8px)` 原地隐身，**占位全程保留** |
| 高度地板 | `.wrap.mini { min-height: var(--mini-h) }` | 删除（`--mini-h` 整套机制连测量代码一并移除） |
| 极简内边距 | `padding-top: 24px; padding-left: 20px`（+10px 高度跳变） | 与完整模式一致（14px），不再改内边距 |
| 封面 margin | 极简时 `margin-right: 6px`（横向 6px 跳变） | 删除 |

这样整卡高度**恒等于完整模式高度**，与动画播到第几帧完全无关 —— 不是「补偿」，是根本不产生高度差。
歌词盒 `.lyricbox` 本来就是 `.meta` 里的 `position: absolute` 元素，靠 188px 高度盖到控件原本的位置上；
控件 `visibility: hidden` 后不再绘制，歌词自然透出来，**根本不需要控件腾出布局空间**。

**新增三条防回退防线**（写入测试）：
1. 全仓 `transition` 只允许合成属性 —— 禁止 `all / height / max-height / min-height / padding / margin /
   width / top / bottom / gap / flex`（`.lyricbox` 的 `height` 是唯一例外，因为它绝对定位，不外溢到布局）；
2. `.lyricbox`、`.vol-overlay`、`.panel` 必须 `position: absolute`；
3. `.wrap.mini` 只允许 `overflow`，不得出现任何改变占位的属性；`--mini-h` / `_miniFullH` 不得再出现。

顺带把流转页回收站的 `transition: all 0.15s` 改成显式属性（`border-color / color / background`），
消除 `all` 这种「将来可能误伤布局」的写法。
