## MusicFlow 卡片 v2.8.0 — 首页取消群组增减成员，流转页改用勾选态

### 变更

- **首页播放器 chip 行不再管理群组**：点任何 chip（含群组）都只切换遥控目标，
  不再进入「成员管理模式」，也不再在设备下方渲染加入 / 退出圆圈与提示条。
  群组增减成员统一收敛到整卡流转页。
- **流转页成员控件改为勾选 / 非勾选**：原来封面圆右上角的 `+ / −` 改为同一个勾选圈 ——
  未加入显示空心圈（○），已加入显示强调色实心 ✓；位置、点击热区、无障碍属性不变，
  仅表达方式从「加减号」换成「勾选态」。
- 流转页提示条文案同步改为「点设备右上角圆圈勾选 / 取消勾选加入该群组」。
- 移除首页成员管理相关的状态、方法、CSS 与中英文文案（`groupManage`、
  `outputs.groupManageHint`、`.out-badge`、`.gm-hint`、`.outputs.managing`）。

### 测试

- 新增 / 更新回归守卫：首页不得再出现成员勾选圈与管理提示条；点群组 chip 只切目标；
  流转页成员控件必须两态都渲染 ✓（已加入实心 + `aria-pressed="true"`）。
- 首页 chip 单行版式守卫同步去掉 `.outputs.managing` 的换行回退断言。
