# v2.8.8

**类型**: 修复（首页选中播放器芯片的配色与投影裁切）

## 改动一：选中播放器的文字 / 图标改为固定色

**问题**：首页被选中的播放器芯片，其文字和图标颜色会随当前曲目变化——浅色封面时浅字压在浅色高亮底上近乎不可见。

**根因**：选中态 `.out.active` 的文字（`color`）与图标（`.ic`）都取自 `rgb(var(--acc))`，
而 `--acc` 是从**当前曲目封面像素提取的强调色**（`accentRgb`，换歌即重算），
与芯片自己的背景渐变（`rgba(var(--acc), .32 → .10)`）同源。
即「文字色」和「底色」被同一个逐曲变化的变量绑在一起。
未选中芯片反而用固定色 `var(--ctl)`，所以只有被选中那台会变色。

**修复**：文字与图标改为恒取 `var(--fg)` —— 卡片当前明暗档的固定前景
（默认 `#ffffff` 白字 / `.dark` 档 `#1b1b1f` 深字，与未选中态 `--ctl` 同档但更实，保留区分度）。
背景渐变与边框仍跟随 `--acc`，选中态的「立体 + 跟随封面」观感不变。
文字投影改为按档位取 `--sel-text-shadow`（白字深投影 / 深字浅投影），保证压在任意 accent 底色上都可读。

## 改动二：底部立体投影不再被容器切断

**问题**：选中芯片底部的立体投影被容器切成一条直线，看不到向下的过渡。

**根因**：`.out-list` 为横向滚动容器（`overflow-x: auto`），纵向实际落在 `overflow-y: hidden`，
而纵向 padding 只有 4px；选中态 `box-shadow` 原为 `0 8px 22px`，向下伸出约 19px，远超 4px 的留白 ⇒ 被硬切。

**修复**：
- `.out-list` 纵向 padding `4px` → `10px`，给 `scale(1.12)` 与投影留出绘制空间；
- 选中态投影收窄为 `0 2px 3px rgba(0,0,0,.45), 0 4px 9px rgba(0,0,0,.5)`（仍有明显上浮立体感，但能完整容纳）；
- 悬停态投影同步收窄为 `0 3px 8px`（原来是 `0 4px 14px`，同样会被切）。

> 副作用：播放器 chip 行纵向高度 +12px（芯片上下留白变大，选中态不再贴边）。
> 若希望行高不变，可用负 margin 抵消 padding，需要再说。

## 兼容性
- 仅样式改动，不涉及传输 / 鉴权 / 逻辑。
- `--sel-text-shadow` 为新增变量，两个明暗档均已定义。
