## MusicFlow 卡片 v2.6.0 — 流转页与首页 chip 体验升级

本版围绕「流转播放」补齐全屏流转页与拖拽时的边缘自动滚动，并把首页播放器 chip 收敛为恒单行。

### 新增：流转播放页

卡片新增「流转播放」入口，点开即是一张**与卡片同尺寸的满覆盖流转页**（不改变卡片布局、不跳出仪表盘）：

- **单击**某个圆 = 切换遥控目标（当前目标自动关页）；点空白处关闭。
- **拖拽**某个圆到另一个圆 = 把源端队列流转给目标端，流转成功后控制自动跟到目的地。
- **群组**：点群组圆选中后，每个设备圆下方出现 `+` / `−`，即可加减组内成员。
- **回收站**：拖到右下角回收站松手 = 销毁该端（不关闭页面），与流转落点互斥。
- **拖拽边缘自动滚动**：拖到列表上下边缘 44px 隐形热区即连续滚动，越靠边越快
  （140–1100 px/s）；到达边界、无滚动空间、进入回收站均自动停止；松手按指针
  **实际坐标**重新判定落点，滚动过程中幽灵跟手、高亮实时刷新。

### 改进：首页播放器 chip 恒单行

- `.outputs` 取消换行，溢出**不在首页展示**，避免卡片被 chip 撑高。
- 当前遥控目标**始终可见**（自动滚到视口内），标签单行省略，active 缩放不再被裁切。

### 修复

- 指针按下不再 `preventDefault`：旧逻辑会抑制触屏补发的 `click`，导致触屏上点选失效。
- 拖拽补指针捕获 + 窗口失焦兜底：指针异常丢失时自动结束本次拖拽，不再残留
  `_tpDrag` 卡死后续操作。
- 源端队列为空（`transferred=0`）不再误报流转成功、不再 reset 源端，改为提示空队列。
- 拖拽期间禁用文本选择，避免拖动时选中名称文字。

### 测试

- 新增 3 条落地后审查回归守卫（触屏 click、失焦兜底、空队列），单测 **281 例全通过**。
- 230 HA 实测 40 项断言全通过（首页单行、满卡流转页、点选切换、跨协议流转、
  群组加减、回收站销毁、25 端自动滚动深度调速与边界停止）。
