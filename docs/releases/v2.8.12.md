# v2.8.12

## Fix

### 极简歌词模式：点击只退出极简，不再误触发控件

**现象**：进入极简歌词模式后点卡片（空白处），会误触发播放/暂停、收藏、音量、切换器等控件。

**根因（不是 CSS 隐身没生效，而是时序）**：
1. 桌面的 `pointermove`、触屏的 `pointerenter` 都在 `click` **之前**就把极简模式退掉了；
2. 控件退出瞬间立刻 `visibility: visible`（展开态 visibility 延迟为 0，这是刻意的：动画一开始就可见可交互）；
3. 于是同一次手势末尾的那个 `click`，命中了刚露出来的按钮 —— 「点空白却切了歌」。

**修复（两步）**：
- **触屏（`pointerType === "touch"`）不在按下/滑动阶段退出极简**，留到 `click` 统一退出（长按也覆盖，长按期间不会中途露出控件）；
- 在 **host 的捕获阶段**新增守卫 `_onWrapClickCapture`：极简中、或刚退出 `MINI_CLICK_GUARD_MS`（300ms）内的那一击被吞掉——`stopPropagation()` 在捕获阶段就截断，控件自己的 handler 根本不会执行，只做一件事：退出极简模式并重置空闲计时。
  - 窗口取 300ms：盖住「移动即点」的连击，又短于人的反应时间，看清控件后的正常点击不受影响；
  - 只吞一击（吞完立即清戳），已经处于退出态时不会再刷新戳，鼠标持续移动不会把窗口无限延长。

桌面行为保持不变：鼠标移入即唤出控件（悬停退出）。

## Feature

### 动画节奏整体翻倍（v2.8.11 反馈偏快）

| 项目 | 原值 | 现值 |
|---|---|---|
| 进场时长 `--dur-in`（面板/音量/首页内容/极简展开） | 0.3s | **0.6s** |
| 出场时长 `--dur-out`（面板/音量关闭、首页内容隐身） | 0.22s | **0.44s** |
| 极简模式三块淡出 opacity | 0.25s | **0.5s** |
| 极简歌词盒扩展高度 | 0.42s（delay 0.18s） | **0.84s（delay 0.36s）** |
| 极简歌词盒收缩高度 | 0.3s | **0.6s** |
| 歌词轨道滚动 transform | 0.45s | **0.9s** |
| 当前行高亮 color/opacity | 0.3s | **0.6s** |

曲线不变（进场 `cubic-bezier(0.2,0,0,1)` / 出场 `cubic-bezier(0.4,0,1,1)`），只放慢节奏。
面板/音量/首页内容全部走全局变量，改这两个值即可全局生效。

**未翻倍**：按钮悬停、边框、封面缩放等 0.18–0.2s 的微反馈保持原速——这类反馈放慢会让点击手感发滞；
如需一并放慢请单独提。
