## MusicFlow 卡片 v2.8.1 — 流转页选中态与群组勾选统一改为红色 ✓

### 变更

- **选中（当前遥控）播放器**：不再用封面圆外的白色描边/光晕表示选中，
  改为在封面圆**内部正中**显示红色 ✓（深色半透明衬底，任何封面图上都清晰）。
- **已加入群组的播放器**：右上角勾选圈里的 ✓ 由白色改为同一抹红色；
  实心强调色底与边框保持不变，「已加入」的识别度不受影响。
- 两处红色统一为 `#ef4444`，与客户端/Web 的红勾口径一致。

### 测试

- 新增静态契约守卫 A3：`.tp-cur` 必须居中 + 红色、`.tp-badge.in` 必须红色、
  `.tp-peer.current .tp-ring` 不得再出现 `box-shadow`（白色外环）。
- 单测 E2 改为断言「选中态不再有外环」，新增 E7 锁定红勾颜色与位置。
