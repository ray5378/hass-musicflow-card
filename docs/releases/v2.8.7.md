# v2.8.7

**类型**: 调优（无行为破坏性改动）

## 改动
- 将直连探测 / 登录握手超时 `PROBE_TIMEOUT` 从 **4s 降到 1s**（`src/backend-client.js`）。

## 为什么
- 局域网内后端响应通常是毫秒级，4s 纯属浪费；跨网段 / 外网本就直连不通，等再久也连不上。
- 缩短后：auto 模式在「直连不可达」时更快回落 HA 中转（最坏路径从 8s 降到 2s，针对仅用户名/密码场景：登录 POST + me 探测各 1s）；可达的直连判定更快落位。
- 1s 相对 500ms 多留了冷启动 / 首次 TLS 握手 / Pi 级设备抖动余量，避免误判「直连不可达」而白白走中转。

## 兼容性
- 不改变传输逻辑、鉴权逻辑、回切逻辑；现有 `apiKey` / 用户名密码 / 代理三类凭据路径行为不变。
- 仍仅在纯调试日志里记录探测结果，切换连接方式无 UI 提示。

## 测试
- 全量测试通过（292 用例）。
- 回归确认：有 url 无凭据仍返回 false；仅用户名/密码先登录再探测返回 true。
