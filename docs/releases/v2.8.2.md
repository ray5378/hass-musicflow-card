## MusicFlow 卡片 v2.8.2 — 选中态改为外圈呼吸光环，频谱底色固定

### 变更

- **去掉封面圆内的选中标记**：不再在圆内画深色圆 + 红色 ✓，选中不再占用封面视觉。
  群组成员勾选圈（右上角）保持原样，✓ 仍为红色。
- **选中态改为外圈的呼吸光环**：与客户端流转页 `_ActivePulse` 同一套手感 ——
  56px 圆环从 1.0 放大到 1.26 并渐隐，`1.2s ease-in-out` 往返循环，带 accent 柔光。
  光环画在封面圆之下（DOM 前置节点），不遮挡封面与频谱徽标。
- **「正在播」频谱徽标底色固定**：原先用强调色 `rgba(var(--acc), .92)`，而强调色随
  当前曲封面重算，切换遥控目标时徽标会跟着换色，看起来像选中态在改频谱底色。
  现改为中性深灰 `rgba(38, 38, 41, 0.92)` + 轻微投影，跳动的白条不受影响。
- `prefers-reduced-motion` 下光环静止（定格 1.08 倍、半透明），频谱不再跳动。

### 测试

- 守卫 A3 重写：不得再出现 `.tp-cur`；`.tp-pulse` 必须为 3px accent 圆环 +
  `1.2s ease-in-out infinite alternate`；关键帧必须放大到 1.26；
  `.tp-peer.current .tp-ring` 不得有 `box-shadow`；`.tp-live` 底色不得引用 `--acc`。
- 新增守卫 A4：已加入群组的 `.tp-badge.in` ✓ 仍为红色。
- 单测 A4 改为断言当前端渲染 `.tp-pulse`、不再渲染 `.tp-cur`；E7 重写为呼吸光环与
  频谱底色固定的静态契约。
