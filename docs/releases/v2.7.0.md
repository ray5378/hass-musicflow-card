## MusicFlow 卡片 v2.7.0 — 默认强制经 HA 集成中转

本版把卡片的默认传输通道从「自动探测」改为「始终经 Home Assistant 集成中转」，
用于评估中转链路的实际延迟。直连与自动探测**仍然保留**，YAML 显式指定即可切回；
若中转延迟与直连差距可接受，后续版本再移除直连。

### 变更：默认 transport 改为 proxy

- 未写 `transport` 时一律走 HA 集成中转：REST 经 `/api/musicflow/rest/*` 由集成转发，
  事件经 `musicflow/subscribe` 订阅转发，封面经集成带鉴权拉取后以 blob 渲染。
- 浏览器不再需要能直连后端，也不再受混合内容 / PNA / CORS / 私有 IP 不可路由影响。
- 显式 `transport: direct` / `transport: auto` 行为不变，可随时切回对比。

### 诊断：集成不支持代理时明确告警

- 若 `transport: proxy` 但集成版本过旧（未上报 `proxySupported`），卡片回落直连，
  并在控制台输出 `transport=proxy 但集成不支持代理 -> 回落直连`，
  避免「以为在测中转、其实走了直连」。
