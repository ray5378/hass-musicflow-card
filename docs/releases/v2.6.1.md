## MusicFlow 卡片 v2.6.1 — 流转入口与命中范围精修

本版是对 v2.6.0 流转页的实机复审修复：入口按钮与客户端对齐、选中态不再越界被裁切、点选/拖拽只认封面圆，首页 chip 行支持按住横向拖动。

### 改进：流转入口按钮

- 图标换成与客户端 `AppIcons.transferInfinity` 同形的**无限循环（∞）**标志，
  按钮上不再带「流转播放」文字，只留图标（`aria-label` / `tooltip` 仍为「流转播放」）。
- 去掉外框与底色，与 MINI 播放器控制行的 `.ctl` 同款：透明底、无边框，
  hover 放大上浮 + 中性阴影，按下回缩。

### 修复：流转页选中态越界

- 选中/悬停/焦点效果全部收敛到**封面圆**上：格子（`.tp-peer`）不再画整格底色，
  避免圆外的底色与光晕被卡片边缘裁出「左右黑边」。
- 网格左右各留 8px，光晕收窄到 7px，选中态完整落在视口内。

### 修复：命中范围只认封面圆

- `role` / `tabindex` / 单击 / 键盘 / 拖拽起手全部从整格移到 `.tp-ring`：
  圆下方的播放器名称、「正在播放中」等文字不再响应点选与拖拽。
- 拖拽落点判定同步收窄为 `elementFromPoint → closest('.tp-ring')`。
- 补按下位置判定：从名称/文字上按下、在空白处松手时，浏览器补发的 click
  落在两点共同祖先（`.tp-grid`）上，不再被误判成「点空白」而关页。

### 新增：首页 chip 行按住横向拖动

- 一排放不下的播放器可直接在首页按住任一 chip 左右拖动查看并点选。
- 鼠标/笔走 JS 拖动，横移超过 8px 才进入拖动（不误触切换目标）；
  触屏走原生 `pan-x` 滚动。按需求**不加惯性滑动**，松手即停。
- 拖动结束后 350ms 内吞掉浏览器补发的 click，杜绝「拖完就切台」。
- 滚动条隐藏，拖动中显示抓手光标；群组管理的 `✓` 徽标上按下不进入拖动。

### 其他

- 修正版本号：v2.6.0 发布包横幅仍显示 `2.5.2`（源码 `CARD_VERSION` 未同步），
  本版 `CARD_VERSION` 与 `package.json` 统一为 `2.6.1`。

### 测试

- 单测 **288 例全通过**（新增 E1–E6 回归守卫：图标/无文字、无外框、选中态收敛、
  命中范围、横拖阈值与吞 click、名称起拖不关页）。
- 版本守卫、卡片 UI 契约（15/15）、客户端链接守卫（17/17）、seek 契约守卫全部通过。
- 230 HA 实测 **23/23 通过**：19 个播放端、chip 行可横滚（2675 > 420）、
  按住左拖 140px 不误切、点名称无响应、点圆正常切台、无前端报错。
