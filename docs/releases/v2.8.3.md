## MusicFlow 卡片 v2.8.3 — 修正呼吸光环圆心偏移

### 问题

v2.8.2 新增的选中态呼吸光环与封面圆不同心，真机上看明显偏下。

### 根因

- `.tp-ring` 没有设 `box-sizing: border-box`，所以封面圆的**外径**是 `56px` 内容 + 上下左右各 `2px` 边框 = **60px**，圆心在 border box 中心。
- `.tp-pulse` 是 `.tp-ring` 的兄弟节点，按 `56px` 尺寸 + `left: calc(50% - 28px)` 硬算位置，直径小了 4px；`top: 6px` 起算的高度 56 → 圆心比封面低 2px。

### 修复

- 光环改为 `60 × 60`、`top: 6px`、`left: calc(50% - 30px)`，与封面圆的 **border box** 完全重合：外径相等、顶点齐平、水平居中。

### 测试

- 新增守卫 A5：按算式反查同心关系，而不是钉死单一像素值 ——
  `pulse.width == ring.width + ring.border×2`、`pulse.height` 同上、
  `pulse.top == peer.padding-top`、`left 的负向偏移 == pulse.width/2`。
  任何一处被单独改动都会在 CI 报红。
- 单测 E7 补上 `60px × 60px` 的静态断言。
