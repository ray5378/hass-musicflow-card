# v2.8.11

## Feature

### 五处状态切换：硬跳 → 带方向线性过渡动画

首页的状态切换全部从「0 毫秒瞬间跳变」改为顺滑的带方向过渡动画：

| 场景 | 进场 | 出场 |
|---|---|---|
| 音量面板（volmode） | 音量条从下方 20px 滑上淡入 | 反向滑出 |
| 队列 / 媒体库 / 流转页（panelmode） | 面板从下方 20px 滑上淡入 | 反向滑出 |
| 首页内容（切换器/正在播放/控件/进度） | — | 下沉 8px 淡出，回归时反向 |
| 极简歌词模式（mini）进出 | 控件/切换器/进度条 max-height 收缩 + 淡出，与歌词盒扩展协调 | 反向 |

**缓动（柔和档，行业标准的非对称节奏）**：
- 进场：`cubic-bezier(0.2, 0, 0, 1)`（ease-out，快进慢停）300ms
- 出场：`cubic-bezier(0.4, 0, 1, 1)`（ease-in，慢起快走）220ms
- 全局变量 `--anim-in / --anim-out / --dur-in / --dur-out` 统一管理
- 极简模式的歌词盒既有高度动画（0.42s 扩展 / 0.3s 收缩）原样保留

**可访问性**：
- 隐藏元素用 `visibility` 延迟切换——动画期间保持可见可交互，动画结束后才真正不可见
  （不可 Tab、点击穿透），无需 inert 属性
- `@media (prefers-reduced-motion: reduce)` 覆盖全部新增过渡：系统开「减弱动态效果」时
  退化为直切（保持旧行为）

**结构改造（本版核心工程量）**：
- 面板从「条件挂载」（`showQueue ? 渲染 : ""`）改为**常驻 DOM + `.open` class 切换**，
  Lit 复用节点，每秒进度 tick 不会打断动画
- mini 模式三块（切换器/控件/进度条）从 `display: none` 改为 `max-height` 收缩
  （54/42/22px → 0，各自实际值）+ 淡出——`display:none` 不占位才能保持整卡高度，
  改造后占位随动画消失，配合 `--mini-h` 机制整卡高度零跳变
- 媒体库面板修复「首次打开无动画」：面板壳无条件渲染（同一模板输出壳 + 内部内容条件渲染）。
  踩坑记录：若空栈时返回**另一个模板结构**的壳，Lit 首开时会交换模板、换掉整个节点，
  新节点没有起始渲染态，transition 照样不播——壳必须来自同一个模板

**实测**（QA 独立 Chrome headless CDP 探针，33 + 8 项全部通过）：
- 进出场均有完整中间帧（逐帧采样 translateY 20→0 连续插值、opacity 单调过渡）
- visibility 延迟实测成立：动画全程 visible、结束后 hidden
- 卡片高度零跳变：panelmode/volmode 前后高度差 0；mini 进出整卡高度恒定
- 关闭动画窗口期（~220ms）连点 12 次：flag 与 .open 严格同步、无残影无卡死
- 关闭完成后面板不可 Tab、点击穿透到下层
- loaders（`_qEnsureLoaded` 等）仍只在面板打开时触发，常驻化未引入空跑
