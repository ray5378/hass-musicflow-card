# v2.8.15

## Fix

### 极简歌词模式：带方向进出场 + 歌词/封面归位（v2.8.13 方案作废后重做）

**背景**：v2.8.13 为了「动画不改卡片高度」让三块改为只隐身不收缩，结果歌词与封面停在完整模式的位置——
卡片顶部空出切换器腾出的 64px、歌词视口被往下挤并被裁掉一截（主理人实机反馈「歌词和封面都偏移了位置」），
而且三块统一 `translateY(8px)` 没有方向感。**v2.8.13 已回退**（main 恢复到 v2.8.12 代码，作为 v2.8.14 发布），
本版在新基线上重做。

**新方案**（效果图已确认）：

| 区域 | 进极简 | 回归（出极简） |
|---|---|---|
| 切换器行（上半） | `translateY(-200%)` **向上移出卡片** + 淡出 | 从上方滑回原位 |
| 歌词 + 封面（`.now`） | 上移 `--mini-shift`（= 切换器行高 + 12px gap，实测约 64px）**填到腾出的位置** | 向下回到原位 |
| 控件行 / 进度条（下半） | `translateY(260% / 420%)` **向下移出卡片** + 淡出 | 从下方滑回原位 |
| 歌词视口 | 100px → 188px | 收回 100px |
| 整卡高度 | **恒定** | **恒定** |

**关键手法**：位移全部用 `transform`（合成属性，不参与布局），所以「位置正确」和「高度恒定」不再互相矛盾——
v2.8.13 想靠「收缩」来改变位置，必然动高度，这条路是死胡同。三块的占位全程保留（只位移 + 淡出 +
`visibility` 延迟切换），整卡高度恒等于完整模式高度，与动画播到第几帧无关。

- 位移量用**自身高度百分比**而非定值：卡片尺寸随内容变化时，位移量自动跟着变，永远够飞出卡片
  （被 `.wrap.mini` 的 `overflow: hidden` 裁掉 = 「移出卡片」）。
- `--mini-shift` 由 JS 在完整模式下实测 `.outputs` 高度 + 12px flex gap 注入，chip 行数变化也自适应。
- 顺带删掉极简模式的 `padding-top: 24px / padding-left: 20px / 封面 margin-right: 6px` 覆写
  （这三处都是布局属性，会造成 ±10px / ±6px 硬跳，与「高度/位置稳定」冲突）。
- `--mini-h` 地板机制（`min-height` + `_miniFullH` 整卡高度测量）彻底移除。

**时长**：收起（进极简）走 `--dur-out` 0.44s 缓入曲线，回归走 `--dur-in` 0.6s 缓出曲线，
与面板/音量面板同一套节奏；`prefers-reduced-motion` 下仍全部直切。

## Tests

- 测试 317 → **324 全绿**（+7 条 v2.8.15 守卫）
